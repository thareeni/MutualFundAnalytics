# Mutual Fund Analytics Platform

##  Project Overview

The Mutual Fund Analytics Platform is an end-to-end data analytics project developed as part of the Bluestock Fintech Capstone Internship. The project analyzes India's mutual fund industry using Python, SQL, SQLite, and Power BI to provide meaningful insights into fund performance, investor behavior, SIP trends, and financial risk metrics.



##  Technologies Used

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Jupyter Notebook
- Power BI
- Git
- GitHub
- Matplotlib

## How to Run

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MutualFundAnalytics.git
```

### Open Project

```bash
cd MutualFundAnalytics
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Analysis

Open the Jupyter Notebook:

```
notebooks/03_eda_analysis.ipynb
```

or execute the required Python scripts.

## Dashboard

The Power BI dashboard contains four pages:

- Industry Overview
- Fund Performance
- Investor Analytics
- SIP & Market Trends





## Results

The project successfully:

- Cleaned and validated mutual fund datasets.
- Performed exploratory data analysis.
- Created an SQLite database.
- Computed Sharpe Ratio, Sortino Ratio, Alpha, Beta, Tracking Error, and Maximum Drawdown.
- Developed an interactive Power BI dashboard.
- Performed advanced analytics including VaR, CVaR, Rolling Sharpe Ratio, Investor Cohort Analysis, SIP Continuity Analysis, and Fund Recommendation.
